# ChumFlash

#### Video Demo:  https://youtu.be/A6eHEkgY3dU

#### Description:
This is a flash card application designed primarily for language learning purposes, allowing the user to create, search for, and delete flash cards.
Each flash card has two sides, a front and a back. The user can practice with the available cards by being presented with the front side of a randomly selected card and attempting to recall the back side. If the user answers correctly, he/she is awarded points; Otherwise, the correct answer is displayed.

#### Features:
- During card creation, the back side is automatically generated by the application by translating the front side based on the selected front and back languages. The user can either accept it or enter his/her own one.

- During card creation, the front and back sides are trimmed to remove any excess whitespace, and some proper spacing is added to the text where needed.

- During card creation, a value representing the card’s complexity is calculated and assigned. This value is later used as the number of points awarded to the user for a correct answer.

#### Files and Classes
- flash_card.py
	The FlashCard class is defined in this file. It represents a flash card with these attributes: id, front, back, tags, category, front_lang, back_lang, complexity	
- flash_card_repo.py
	The FlashCardRepo class is defined in this file. It acts as a repository for storing flash cards. Now, it uses a file named flash_cards.csv for this purpose, but it can be replaced with a relational database. 
- project.py
	It is the top level file that contains main() method. Due to project requirements, three other methods, which are used mainly during card creation, are defined in this file and are passed as function parameters to the UserInterface class.
- user_data.py
	The UserData class is defined in this file. It serves as the data layer for storing user settings and the user's latest score. These values are persisted in a file named user_data.txt using JSON serialization.
- user_interface.py
	The UserInterface class is defined in this file. It manages the menu presented to the user to provide access to the application's available actions.

- test_project.py
	This file contains unit test functions to test the functions defined in the project.py file except the main() function.

#### Dilemmas
- There was some doubt about whether to use automatic language detection or let the user set the language manually. However, since many different languages share common words, automatic detection could wrongly identify the language especially for short phrases. For this reason, the manual approach was chosen.

- for implementing the UserData class, at first, an approach using a csv file was considered. but it was not flexible enough to add new parameters easily in the future. so a JSON-based text file was used instead.
